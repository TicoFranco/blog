# Blog

Este projeto foi desenvolvido a partir de um desafio da plataforma DIO (Digital Innovation One). Além dos requisitos propostos originalmente, foram implementadas funcionalidades adicionais, como autenticação de usuários, gerenciamento de perfil, sistema de comentários e interação entre usuários, explorando conceitos de uma aplicação completa.

## Tecnologias

- Next.js
- React
- TypeScript
- Fastify
- Prisma
- PostgreSQL
- JWT
- TailwindCSS

## Funcionalidades

- Cadastro de usuários
- Login e logout
- Edição de perfil
- Seleção de avatar
- Criação de posts
- Edição de posts
- Exclusão de posts
- Sistema de comentários
- Autenticação JWT
- Proteção de rotas

## Como executar

- npm install
- npm run dev
